# Portfolio Website

A modern, minimalistic portfolio website for José Diogo Romano - Machine Learning Engineer.

## Features

- Clean, modern design with blue tones, white, and black color scheme
- Fully responsive layout
- Optimized for GitHub Pages
- Professional presentation highlighting ML engineering and business experience

## Setup for GitHub Pages

1. Push this repository to GitHub
2. Go to your repository settings
3. Navigate to "Pages" in the left sidebar
4. Under "Source", select the branch (usually `main` or `master`)
5. Your site will be available at `https://[your-username].github.io/portefolio-website-page/`

## Customization

### Adding Your Profile Picture

Replace `profile-placeholder.png` with your own profile picture. Supported formats: JPG, PNG, or SVG.

Recommended:
- Square aspect ratio (1:1)
- Minimum 400x400 pixels
- Professional headshot

### Updating Content

Edit `index.html` to update any information, add new sections, or modify existing content.

### Styling

Modify `styles.css` to customize colors, fonts, spacing, or layout. The color scheme uses CSS variables defined in `:root` for easy customization.

## Files

- `index.html` - Main HTML structure
- `styles.css` - All styling and responsive design
- `profile-placeholder.png` - Placeholder profile image (replace with your photo)

## Browser Support

Modern browsers (Chrome, Firefox, Safari, Edge) with CSS Grid and Flexbox support.
